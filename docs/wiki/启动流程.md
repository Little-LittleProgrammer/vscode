# 最最基础的流程

## 启动新窗口

### 文件路径

#### `main.ts`

1. `startup`

#### `/vs/code/electron-main/main.ts`

1. `startup`
	- 初始化服务， 将环境服务，用户数据，配置等等服务初始化，放到 `instantiationService` 中, 方便后续使用
	- 启动主实例
		- 从 `instantiationService` 中获取 日志、生命周期，文件等服务
		- 创建主实例， 进入 `vs/code/electron-main/app.ts` 的 `startup` 方法

#### `/vs/code/electron-main/app.ts`

1. `startup`
	1. 初始化共享进程
	2. 创建app实例服务
		- 将所有的服务放到 `appInstantiationService` 中, 方便后续使用
	3. 从 `appInstantiationService` 中来初始化：错误遥测、认证处理程序、瞬态配置文件处理程序、初始化通道,
	4. 主进程中建立与各个进程之间的通道 mainProcessNodeIpcServer.registerChannel
	5. 初始化 url 处理程序，主要用于判断是不是 vscode:// 协议启动的
	6. 打开窗口 `openFirstWindow`
2. `openFirstWindow`
	1. 获取 `windowsMainService` 服务
	2. 判断是不是 vscode:// 协议启动的
	3. 打开窗口 `windowsMainService.open` 执行 `src/vs/platform/windows/electron-main/windowsMainService.ts`

#### `src/vs/platform/windows/electron-main/windowsMainService.ts`

1. 执行 `open` 方法
2. 执行 `doOpen` 方法
3. 执行 `doOpenEmpty` 方法
4. 执行 `openInBrowserWindow` 方法, 实际创建或复用 Electron 窗口，并加载配置。
	- 窗口事件窗口监听，监听准备就绪事件，窗口关闭事件，窗口销毁事件，窗口最大化事件等等
5. 执行 `doOpenInBrowserWindow` 方法, 加载窗口配置并注册备份、配置文件等。
	- window.load()

#### `src/vs/platform/windows/electron-main/windowImpl.ts`

1. 执行 `load` 方法
	- loadURL `vs/code/electron-sandbox/workbench/workbench-dev.html`

#### `vs/code/electron-sandbox/workbench/workbench-dev.html`

#### `src/vs/code/electron-sandbox/workbench/workbench.ts`

加载工作台， 正式进入窗口创建流程

- `result.main(configuration)` 执行 `src/vs/workbench/workbench.desktop.main.ts`

#### `src/vs/workbench/electron-sandbox/desktop.main.ts`

1. 执行 `main` 方法
2. 执行 `DesktopMain.open` 方法
	- `Promise.all([初始化服务, DOM准备就绪])`
	- 初始化 `workbench` 服务
	- 执行 `workbench.startup`

#### `src/vs/workbench/browser/workbench.ts`

1. 执行 `startup` 方法
	- 初始化 `workbench` 服务
	- 执行 `workbench.startup`

#### `src/vs/workbench/browser/part.ts`

1. 执行 `startup` 方法
	- 初始化服务 `initServices`： 生命周期、存储、配置、host、hover、通知等等服务
	- 调用 `renderWorkbench` 方法 渲染工作台
2. 执行 `renderWorkbench` 方法
