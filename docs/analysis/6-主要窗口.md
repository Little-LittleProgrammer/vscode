# 主要窗口

VSCode 的主窗口实现了灵活的布局系统，支持多种视图和面板的组合展示，提供了高度可定制的用户界面体验。

## 整体加载步骤概览
1. `src/vs/code/electron-sandbox/workbench/workbench.html` 主要窗口的 HTML 文件
2. `src/vs/code/electron-sandbox/workbench/workbench.ts` 主窗口的入口脚本
3. `vs/workbench/workbench.desktop.main` 工作台的入口脚本
4. `src/vs/workbench/electron-sandbox/desktop.main.ts`，加载完上面的后，调用 main 方法
5. `src/vs/workbench/browser/workbench.ts`，加载完上面的后，调用 startup 方法

## 窗口架构

VSCode 的窗口系统基于 Electron 的窗口管理，主要分为以下几个层次：

### 1. 窗口创建与管理

在 `src/vs/platform/windows/electron-main/windowsMainService.ts` 中，`WindowsMainService` 负责窗口的创建和生命周期管理：

```ts
export class WindowsMainService implements IWindowsMainService {
	/**
	 * 打开一个空窗口（无文件/文件夹/工作区）。
	 * @param openConfig 打开配置
	 * @param options 额外选项
	 * @returns 打开的窗口数组
	 */
  	openEmptyWindow(openConfig: IOpenEmptyConfiguration, options?: IOpenEmptyWindowOptions): Promise<ICodeWindow[]> {
		const cli = this.environmentMainService.args;
		const remoteAuthority = options?.remoteAuthority || undefined;
		const forceEmpty = true;
		const forceReuseWindow = options?.forceReuseWindow;
		const forceNewWindow = !forceReuseWindow;

		return this.open({ ...openConfig, cli, forceEmpty, forceNewWindow, forceReuseWindow, remoteAuthority, forceTempProfile: options?.forceTempProfile, forceProfile: options?.forceProfile });
	}

	openExistingWindow(window: ICodeWindow, openConfig: IOpenConfiguration): void {}

	open(openConfig: IOpenConfiguration): Promise<ICodeWindow[]> {
}
```

## 主窗口布局系统

VSCode 的主窗口实现了一个复杂而灵活的布局系统，由 `Layout` 类控制：

### 1. 核心布局结构

主窗口由以下主要部分组成：

- **标题栏 (Title Bar)**：显示窗口标题和菜单
- **活动栏 (Activity Bar)**：左侧的图标栏，用于切换侧边栏视图
- **侧边栏 (Side Bar)**：显示资源管理器、搜索、源代码控制等面板
- **编辑器区域 (Editor Area)**：显示文件内容和编辑器
- **面板 (Panel)**：底部区域，显示终端、问题、输出等
- **状态栏 (Status Bar)**：底部信息栏，显示状态信息和操作按钮
- **辅助侧边栏 (Auxiliary Bar)**：右侧边栏，用于额外视图

### 2. 布局管理实现

`Layout` 类在 `vs/workbench/browser/layout.ts` 中实现，管理整个界面的布局和调整：

```ts
export abstract class Layout extends Disposable implements IWorkbenchLayoutService {
  // 主布局容器
  protected readonly mainContainer: HTMLElement;

  // 获取当前布局容器
  private getContainerFromDocument(targetDocument: Document): HTMLElement {
    if (targetDocument === this.mainContainer.ownerDocument) {
      // 主窗口
      return this.mainContainer;
    } else {
      // 辅助窗口
      return targetDocument.body.getElementsByClassName('monaco-workbench')[0] as HTMLElement;
    }
  }

  // 控制部件可见性
  setPartHidden(hidden: boolean, part: Parts): void {
    // 更新部件可见性状态
    this.state.partHidden[part] = hidden;
    // 触发布局更新
    this.layout();
  }
}
```

### 3. 多窗口支持

VSCode 支持同时打开多个窗口，每个窗口有独立的工作台实例：

```ts
export class MultiWindowParts<T extends IMultiWindowPart> extends Component {
  protected readonly _parts = new Set<T>();
  get parts() { return Array.from(this._parts); }

  abstract readonly mainPart: T;

  // 获取当前活动窗口的部件
  get activePart(): T {
    return this.getPartByDocument(getActiveDocument());
  }
}
```

## 上下文系统

VSCode 使用上下文键系统来控制 UI 元素的可见性和行为：

```ts
export class WorkbenchContextKeysHandler extends Disposable {
  constructor(
    @IContextKeyService private readonly contextKeyService: IContextKeyService,
    @IWorkspaceContextService private readonly contextService: IWorkspaceContextService,
    // ... 其他依赖注入
  ) {
    super();

    // 绑定上下文键
    this.sideBarVisibleContext = SideBarVisibleContext.bindTo(this.contextKeyService);
    this.panelVisibleContext = PanelVisibleContext.bindTo(this.contextKeyService);

    // 注册监听器
    this._register(this.layoutService.onDidChangePartVisibility(() => {
      this.mainEditorAreaVisibleContext.set(
        this.layoutService.isVisible(Parts.EDITOR_PART, mainWindow)
      );
      this.panelVisibleContext.set(
        this.layoutService.isVisible(Parts.PANEL_PART)
      );
    }));
  }
}
```

## 启动流程

VSCode 窗口的启动流程由以下步骤组成：
`src/vs/workbench/browser/workbench.ts`

1. **创建窗口**：主进程创建 Electron `BrowserWindow` 实例
2. **加载启动页**：显示启动画面，提供视觉反馈
3. **初始化工作台**：加载工作台主模块，构建 UI 结构
4. **恢复布局**：根据之前保存的状态恢复布局配置
5. **加载服务**：初始化必要的服务
6. **完成启动**：设置生命周期状态为 `Ready`

```ts
export class Workbench extends Layout {
	startup(): IInstantiationService {
		try {
			// 配置发射器泄漏警告阈值
			this._register(setGlobalLeakWarningThreshold(175));

			// 服务
			const instantiationService = this.initServices(this.serviceCollection);

			// 使用服务访问器调用一个函数。
			// 在服务访问器中，可以获取并使用已注册的服务。
			instantiationService.invokeFunction(accessor => {
				const lifecycleService = accessor.get(ILifecycleService);
				const storageService = accessor.get(IStorageService);
				const configurationService = accessor.get(IConfigurationService);
				const hostService = accessor.get(IHostService);
				const hoverService = accessor.get(IHoverService);
				const dialogService = accessor.get(IDialogService);
				const notificationService = accessor.get(INotificationService) as NotificationService;

				// 默认悬停委托必须在创建任何工作台/布局组件之前注册
				// 因为这些可能会使用默认悬停委托
				setHoverDelegateFactory((placement, enableInstantHover) => instantiationService.createInstance(WorkbenchHoverDelegate, placement, { instantHover: enableInstantHover }, {}));
				setBaseLayerHoverDelegate(hoverService);

				// 布局
				this.initLayout(accessor);

				// 注册表
				Registry.as<IWorkbenchContributionsRegistry>(WorkbenchExtensions.Workbench).start(accessor);
				Registry.as<IEditorFactoryRegistry>(EditorExtensions.EditorFactory).start(accessor);

				// 上下文键
				this._register(instantiationService.createInstance(WorkbenchContextKeysHandler));

				// 注册监听器
				this.registerListeners(lifecycleService, storageService, configurationService, hostService, dialogService);

				// 渲染工作台
				this.renderWorkbench(instantiationService, notificationService, storageService, configurationService);

				// 工作台布局
				this.createWorkbenchLayout();

				// 布局 src/vs/workbench/browser/layout.ts
				this.layout();

				// 恢复
				this.restore(lifecycleService);
			});

			return instantiationService;
		} catch (error) {

		}
	}
}
```

## 响应式设计

VSCode 窗口支持响应式布局，可以根据窗口大小调整界面元素：

1. **尺寸感知**：通过 `Dimension` 类跟踪容器大小变化
2. **布局调整**：根据可用空间动态调整部件大小和位置
3. **最小尺寸**：为各部件定义最小尺寸，确保可用性
4. **缩放支持**：通过 `EditorZoom` 服务支持界面缩放

VSCode 的窗口系统通过这种灵活的布局架构，实现了高度可定制的用户界面，同时保持了良好的性能和用户体验。
